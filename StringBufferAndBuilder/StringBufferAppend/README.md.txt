# StringBuffer Append

This program demonstrates the use of the **append()** method in the `StringBuffer` class.

## Description
- `append()` is used to add text at the end of an existing string.
- `StringBuffer` is **thread-safe** and can be used in multi-threaded environments.

## Example
**Input:** "Hello"  
**Operation:** `append(" World")`  
**Output:** `Hello World`
