# StringBuffer and StringBuilder

This folder contains separate Java programs that demonstrate the use of each method in **StringBuffer** and **StringBuilder**.

## StringBuffer
- Demonstrates methods of `StringBuffer` class.

### Files
1. **StringBufferAppend.java** – shows how to use `append()`  
2. **StringBufferInsert.java** – shows how to use `insert()`  
3. **StringBufferDelete.java** – shows how to use `delete()`  
4. **StringBufferReverse.java** – shows how to use `reverse()`

---

## StringBuilder
- Demonstrates methods of `StringBuilder` class.

### Files
1. **StringBuilderAppend.java** – shows how to use `append()`  
2. **StringBuilderInsert.java** – shows how to use `insert()`  
3. **StringBuilderDelete.java** – shows how to use `delete()`  
4. **StringBuilderReverse.java** – shows how to use `reverse()`
