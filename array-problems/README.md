# Array Problems in Java

This repository contains Java programs that solve common array-related problems. Each program is designed to demonstrate key array operations such as insertion, deletion, merging, shifting, and searching.

## Folder: `array-problems`

### Programs List

1. **01_array_length_and_values**
   - Finds the length of an array.
   - Initializes and prints array values.

2. **02_print_alternate_elements**
   - Prints every alternate element of an array.

3. **03_even_odd_count**
   - Counts the number of even and odd elements in an array.

4. **04_sorted_array_check**
   - Checks whether an array is sorted in ascending order.

5. **05_merge_arrays**
   - Merges two arrays into one.

6. **06_add_two_arrays**
   - Adds corresponding elements of two arrays.

7. **07_second_largest**
   - Finds the second largest element in an array.

8. **08_right_shift**
   - Shifts array elements to the right by one or more positions.

9. **09_left_shift**
   - Shifts array elements to the left by one or more positions.

10. **10_copy_array**
    - Copies elements from one array to another.

11. **11_Insertion_array**
    - Inserts a new element at a specified position in an array.
