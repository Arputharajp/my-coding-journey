# Anonymous Object Demo in Java

This program demonstrates the use of **anonymous objects** in Java. 

## What is an Anonymous Object?

An **anonymous object** is an object that is **created without a reference variable**. It is typically used when an object is needed only once, such as when calling a method. 

### Example Usage

```java
new MyClass().myMethod(); // Anonymous object


Here, the object of MyClass is created and used to call myMethod() without storing the object in a variable.

Key Features Demonstrated

Creation of anonymous objects.

Calling methods using anonymous objects.

Understanding the scope and lifetime of objects created without references.

How to Run

Make sure you have Java installed.

Compile the program:

javac AnonymousObjectDemo.java


Run the program:

java AnonymousObjectDemo
